# Steamテキスト Gemini日本語翻訳

Steamの外国語レビュー、コミュニティ投稿、ガイド、ストアのゲーム説明文などに小さな「日本語に翻訳」リンクを追加する、Chrome / Edge向けManifest V3拡張機能です。クリックした文章だけをGemini APIに送り、原文と同じ場所を日本語訳へ切り替えます。ビルド作業や外部ライブラリは不要です。

## 主な機能

- 翻訳はクリック時のみ実行します。ページ内の文章を自動で一括翻訳しません。
- 翻訳後は「原文を見る（Geminiによる翻訳）」、原文表示中は「日本語訳を見る（Geminiによる翻訳）」で何度でも切り替えます。切り替えではAPIを再呼び出ししません。
- 同じ文章の翻訳をローカルにキャッシュし、再表示時にも再利用します。最大200件、保存期間は90日です。設定画面から削除できます。
- 追加読み込みや再描画で現れた文章も検出します。同じ本文へのリンク重複を防ぎます。
- Steamストアのレビューカード・ゲーム説明欄と、コミュニティのレビュー、スレッド、返信、ガイド、ワークショップ作品、スクリーンショット、作品（アートワーク）、ニュース記事の文章に対応します。日本語と判定した文章にはリンクを表示しません。
- 作者名、プロフィール、投稿日、評価ボタンなどのSteam UIは翻訳対象にしません。長いニュースやガイドは段落・節ごとにリンクを表示します。
- 動画・画像・埋め込みがある本文も、翻訳リンクは本文全体で1つです。ストア説明欄では見出しのすぐ下に置き、折りたたみ時にも操作しやすくします。クリック1回で文章をまとめて翻訳し、原文と日本語訳も一括で切り替えます。動画や画像は複製・移動せず、再生ボタンとともに元の位置に保持します。見出し・段落・箇条書きの構造も残し、画像の代替文字やプレイヤーの操作ラベルは送信しません。
- 一括翻訳では、未取得の文章を1回のGemini生成リクエストにまとめます。段落単位の既存キャッシュを再利用し、同じ本文の重複や進行中の要求も共有します。返答の欠落・重複・未翻訳を検出した場合は、本文を一部だけ置き換えず原文を残します。
- 単文・一括翻訳のどちらも、日本語を翻訳先として明示した共通の指示とJSON出力形式を使います。ブラウザ内で原文の言語を信頼して判定できる場合だけ言語ヒントを付け、判定できない場合はGeminiに自動判定させます。トルコ語・ロシア語・ウクライナ語などを特別扱いせず、外国語の原文返送や言い換えを避ける指示を日英で明示します。
- 明らかに未翻訳の応答は成功扱い・保存せず、原文のまま「再試行」を表示します。自動でAPIを再呼び出ししません。判定には文字種と、利用可能な場合はブラウザ内の[言語判定](https://developer.chrome.com/docs/extensions/reference/api/i18n#method-detectLanguage)を使い、追加の外部サービスには送信しません。

## 必要なものと無料枠

- Google ChromeまたはMicrosoft EdgeなどのChromium系ブラウザ
- Google AI Studioで取得したGemini APIキー
- Gemini APIにアクセスできるネットワーク

翻訳モデルは高速な `gemini-3.1-flash-lite` です。Google公式料金表にはこのモデルの無料枠が記載されています。無料枠の回数や利用条件はアカウント、地域、時期で変わり得ます。接続テストはモデル情報を取得するだけで、翻訳を生成しません。

Google公式資料：[モデル](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-lite)・[料金](https://ai.google.dev/gemini-api/docs/pricing)・[APIキー](https://ai.google.dev/gemini-api/docs/api-key)・[GenerateContent API](https://ai.google.dev/api/generate-content)・[構造化出力](https://ai.google.dev/gemini-api/docs/structured-output)

無料枠では、送信した内容がGoogleの製品改善に利用される設定・条件があります。詳細はGoogleの最新の料金表と利用規約を確認してください。

## APIキーの取得

1. [Google AI StudioのAPIキー画面](https://aistudio.google.com/app/apikey)でキーを作成します。
2. キーは自分だけが見られる場所に保管します。README、ソースコード、スクリーンショット、公開リポジトリには貼らないでください。
3. この拡張機能の設定画面にキーを入力します。

## インストール

この `steam-review-translator` フォルダを、そのまま選択してください。ZIPを作る必要はありません。

### Chrome

1. アドレスバーで `chrome://extensions` を開きます。
2. 右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. このREADMEと `manifest.json` が入った `steam-review-translator` フォルダを選びます。

### Edge

1. アドレスバーで `edge://extensions` を開きます。
2. 「開発者モード」をオンにします。
3. 「展開して読み込み」（または「パッケージ化されていない拡張機能を読み込む」）を押します。
4. `steam-review-translator` フォルダを選びます。

コードを更新した後は拡張機能一覧で「再読み込み」を押し、Steamページも再読み込みしてください。コミュニティのレビュー詳細ポップアップを開いていた場合は、一度閉じて開き直してください。

開発者向けのローカル検証は、Node.jsがある環境で `node --test tests/*.test.js` を実行できます。

媒体保持のブラウザ検証は、このフォルダで `node tests/serve-media-check.cjs` を実行し、`http://127.0.0.1:8765/` を開いて行えます。Steamの公開動画を読み込みますが、翻訳応答はモックで、APIキーやGemini APIの無料枠は使いません。実DOM・CSSで、媒体の保持、再生操作、原文切り替え、動的追加を検証します。サーバーはこの端末だけで待ち受け、終了はCtrl+Cです。

## 設定と使い方

1. 拡張機能一覧で本拡張機能の「詳細」→「拡張機能のオプション」を開きます。
2. Gemini APIキーを入力して「保存」を押します。「接続テスト」で利用可能なモデルを確認できます。
3. Steamストアの商品ページまたはSteamコミュニティの投稿・ガイドなどを開きます。
4. 翻訳したい本文のそばの「日本語に翻訳」をクリックします。
5. 翻訳後は「原文を見る（Geminiによる翻訳）」で原文へ、「日本語訳を見る（Geminiによる翻訳）」で訳文へ切り替えます。

APIキーがない場合は「設定を開く」リンクが表示されます。通信失敗時は原文を残し、「再試行」を表示します。

## キャッシュ

本文のSHA-256ハッシュをキーにし、翻訳文を `chrome.storage.local` に保存します。ユーザー名、Steam ID、プロフィール、ゲーム名、投票数などの周辺情報はGeminiへ送信しません。送信するのは翻訳指示とクリックした文章の本文のみです。ただし、投稿者が本文自体に名前を書いた場合や引用文に名前が含まれる場合は、その文章の一部として送信されることがあります。引用の作者表示は抽出時に除外します。

キャッシュは最近利用したものから最大200件を保持し、保存から90日を過ぎたものは利用しません。キャッシュへのアクセス時に期限切れ・件数超過のデータを削除します。旧版で管理一覧から漏れたデータも、バックグラウンドの初回利用時に整理します。設定画面の「翻訳キャッシュを削除」で消去できます。APIキーの削除とキャッシュの削除は別操作です。

以前保存された訳文も、翻訳リンクをクリックした時に検証します。未翻訳と判定されたキャッシュはその文章の分だけ除去し、そのクリックによる要求で新しく翻訳します。ほかの有効な訳文やAPIキーは消去しません。すでに開いているページ内で保持している訳文は、拡張機能とSteamページを再読み込みすると更新されます。

## トラブルシューティング

- リンクが出ない：Steamページを再読み込みしてください。本文が日本語と判定された場合も表示されません。
- APIキー未設定：設定画面でキーを保存してください。
- 認証エラー：キー、Google AI Studioのプロジェクト、Gemini APIの利用可否を確認してください。
- レート制限：時間を置いて「再試行」してください。連打しても同じ文章への並行リクエストは行いません。
- 訳文が出ない：通信状態を確認し、拡張機能を再読み込みしてください。候補が返らない場合や翻訳が途中で止まった場合は、原文のままエラーを表示します。
- 「日本語への翻訳を確認できませんでした」：Geminiが原文や外国語の言い換えを返した可能性があります。「再試行」で再要求できます。未翻訳と判定した応答はキャッシュしません。
- 旧版で長い外国語レビューの翻訳が失敗した：1.1.5では翻訳指示と単文の出力形式を改善しています。拡張機能を再読み込みし、Steamページも再読み込みしてから試してください。有効な既存キャッシュやAPIキーを削除する必要はありません。
- Steamの表示が更新された：拡張機能とページを再読み込みしてください。SteamのHTML変更により本文検出が外れる場合があります。

## セキュリティと既知の制限

- APIキーは拡張機能のローカルストレージに保存します。端末・ブラウザのプロファイルを共有する場合は注意してください。キーをソースコードへ記入したり公開したりしないでください。
- ブラウザ内の拡張機能はユーザーのAPIキーで直接Geminiにアクセスします。厳密な秘密管理が必要な組織用途では、独自のサーバー経由の構成が必要です。
- 言語判定はSteamが明示する言語と簡易的な文字判定です。短文や漢字だけの文章では誤判定があり得ます。
- 訳文の検証も完全な言語・意味判定ではありません。固有名詞、略語、漢字だけの短文は未翻訳との区別が難しく、判定に限界があります。CEF等でブラウザの言語判定APIがない場合は文字種だけで判定するため、正しい訳文を拒否する場合もあります。
- 本文の改行と絵文字は可能な限り保持しますが、AIの翻訳結果や元のHTML装飾の完全な再現は保証できません。
- 動画・画像がある本文は内部で文章と配置の対応を管理しますが、操作リンクは1つだけです。媒体そのもの、画像内の文字、動画の音声・字幕は翻訳しません。キャッシュ済みの部分は送らないため、新しく翻訳する部分の文脈は未取得部分に限られます。
- SteamのページやカードのDOMが変わると、リンクが表示されなくなる可能性があります。サイト全体のUI文字列やプロフィール名は対象外です。
- 1回の翻訳対象が合計16,000文字、または一括翻訳で256部分を超える場合はエラーを表示します。長いニュース記事は段落単位、ガイドは節単位で翻訳できます。ゲーム説明欄は全体で1単位のため、この上限を超える説明欄は一括翻訳できません。
- 長文がSteam側で表示範囲だけに省略され、全文がDOMにない場合は、表示されている部分だけを翻訳します。全文展開後に本文が変われば以前の訳文を無効にします。
